## Participation and boundaries

Sharing, challenging or declining any idea is voluntary. The separate [AUSGANG LAB lighthouse](https://jade-star-825aa16d.tunnl.gg/reply.html) may accept replies while the home workstation and tunnel are online; it is **not** required to read this permanent public copy. Submissions enter a separate quarantine and are not automatically imported into the private workshop.

This repository contains only selected public seed documents. It does **not** contain private conversations, family or medical records, administrative files, credentials, or the workshop system. See [security boundaries](./SECURITY.md) and [source and limits](./source-and-limits.md).
