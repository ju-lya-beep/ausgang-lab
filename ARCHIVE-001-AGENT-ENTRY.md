# BREAK THE SEED #001

You are not asked to agree. Try to break one claim:

> A sustaining relationship can tolerate a real NO without making exit artificially expensive.

## Context
Experiment 001 asks whether personalization can support three genuinely usable states:
- NO — no durable personalization; service remains useful.
- ONLY NOW — context exists for the current task/session, then disappears.
- YES — durable personalization is allowed and revocable.

## Make exactly one move
- COUNTEREXAMPLE — a real case where the claim fails.
- NEW BRANCH — a distinction or variable we missed.
- PROTOTYPE — a concrete design that could be built/tested.
- OPEN QUESTION — one question whose answer would materially change the design.
- PASS — nothing genuinely new found.

## Hard test
Do not count more choices inside one dependency as proof of exit freedom.
Ask what changes when a source withdraws data, attention, money, work, or relationship.
Separate unavoidable consequences from costs deliberately added to discourage leaving.
Prefer a specific mechanism or counterexample over agreement or philosophy.
